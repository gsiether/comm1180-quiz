📋 Quick Notes

Customer Value

  • CV = ΣBenefits − ΣCosts
  • Multi-attribute: CV = Σ(Importance × Performance)

STP Framework

  • Segmentation → Targeting → Positioning
  • Types: Demographic, Psychographic, Behavioural, Firmographic (B2B)

Porter's Generic Strategies

  • Cost Leadership — low cost, broad market
  • Differentiation — unique, broad market
  • Cost Focus — low cost, niche
  • Differentiation Focus — unique, niche

Ansoff Matrix

  • Market Penetration: existing product, existing market
  • Product Development: new product, existing market
  • Market Development: existing product, new market
  • Diversification: new product, new market (most risky)

Value Proposition Canvas

  • Customer Profile: Jobs, Pains, Gains
  • Value Map: Products/Services, Pain Relievers, Gain Creators
  • Fit: Pain Relievers ↔ Pains; Gain Creators ↔ Gains

Contribution Margin

  • CM per unit = SP − VC per unit
  • CM Ratio = CM per unit / SP = 1 − VC Ratio
  • Total CM = CM per unit × units sold

Break-Even Point

  • BEP (units) = Fixed Costs / CM per unit
  • BEP (revenue) = Fixed Costs / CM Ratio

Multi-Product CVP

  • WACM = Σ(CM_i × Sales Mix %_i)
  • Target units = (FC + Target Pre-tax Profit) / WACM
  • Pre-tax profit = After-tax profit / (1 − tax rate)

Margin of Safety

  • MOS = Actual Sales − BEP Sales
  • MOS % = MOS / Actual Sales × 100

Balanced Scorecard (BSC)

  • Financial — ROI, revenue growth, cost reduction
  • Customer — satisfaction, retention, market share
  • Internal Process — efficiency, quality, innovation
  • Learning & Growth — employee skills, systems, culture

Key Concepts

  • Leading indicator: predicts future performance (e.g. training hours)
  • Lagging indicator: measures past outcomes (e.g. net profit)
  • Strategy map: shows cause-effect links between objectives
  • Developed by Kaplan and Norton (1992)

Lump Sum TVM

  • FV = PV × (1+r)^n
  • PV = FV / (1+r)^n
  • r = (FV/PV)^(1/n) − 1
  • n = ln(FV/PV) / ln(1+r)

Rates

  • EAR = (1 + APR/m)^m − 1
  • APR = m × [(1+EAR)^(1/m) − 1]

Annuities

  • PV (ordinary) = C × [1−(1+r)^−n] / r
  • FV (ordinary) = C × [(1+r)^n − 1] / r
  • Annuity due: multiply ordinary × (1+r)
  • Deferred: PV × (1+r)^−k

Perpetuities

  • PV = C / r
  • PV (growing) = C₁ / (r − g)

Capital Budgeting

  • NPV = CF₀ + Σ[CFₜ / (1+r)^t] — Accept if NPV > 0
  • IRR: discount rate where NPV = 0 — Accept if IRR > r
  • PI = NPV / |Initial Investment| — Accept if PI > 0
  • EAA = NPV × r / [1 − (1+r)^−n]

Decision Rules

  • Independent projects: accept all positive NPV
  • Mutually exclusive: choose highest NPV
  • Different lives: use EAA for comparison
  • NPV is theoretically superior to IRR

Bond Pricing

  • P₀ = C × [1−(1+r)^−n]/r + F/(1+r)^n
  • Premium: coupon rate > YTM → P > face value
  • Discount: coupon rate < YTM → P < face value

Equity Valuation

  • Gordon Growth Model: P₀ = D₁ / (r − g)
  • Required return: r = D₁/P₀ + g
  • Dividend growth: g = Retention Ratio × ROI

Risk & Return

  • HPR = (P₁ − P₀ + Div) / P₀
  • Systematic risk: cannot be diversified (captured by β)
  • Unsystematic risk: firm-specific, diversifiable

CAPM

  • E[Ri] = Rf + βi × (E[RM] − Rf)
  • β = 1: moves with market; β > 1: more volatile; β < 1: less volatile

WACC

  • WACC = wE×RE + wP×RP + wD×RD×(1−TC)
  • V = MVE + MVP + MVD; weights = MV / V

Integration Themes

  • Value created when ROIC > WACC
  • BSC links non-financial drivers to financial outcomes
  • Strategy (Ansoff) → Budgeting (NPV) → Value creation
  • ESG = Environmental, Social, Governance
  • Stakeholder theory: broader than shareholder focus

📐 Formula Reference

Contribution Margin

  • CM per unit = Selling Price − Variable Cost per unit
  • CM Ratio = CM per unit ÷ Selling Price
  • VC Ratio = VC per unit ÷ SP → CM Ratio + VC Ratio = 1

Break-Even

  • BEP (units) = Total Fixed Costs ÷ CM per unit
  • BEP (revenue) = Total Fixed Costs ÷ CM Ratio

Multi-Product CVP

  • WACM = Σ (CM_i × Sales Mix %_i)
  • Target units = (FC + Target Pre-tax Profit) ÷ WACM
  • Pre-tax profit = After-tax profit ÷ (1 − tax rate)

Margin of Safety

  • MOS (units) = Actual Sales − BEP Sales
  • MOS % = MOS ÷ Actual Sales × 100%

Lump Sum

  • FV = PV × (1 + r)^n
  • PV = FV ÷ (1 + r)^n
  • r = (FV ÷ PV)^(1/n) − 1
  • n = ln(FV ÷ PV) ÷ ln(1 + r)

Rates

  • EAR = (1 + APR÷m)^m − 1
  • APR = m × [(1+EAR)^(1/m) − 1]

Ordinary Annuity

  • PV = C × [1 − (1+r)^−n] ÷ r
  • FV = C × [(1+r)^n − 1] ÷ r

Annuity Variations

  • Annuity Due PV = Ordinary PV × (1+r)
  • Deferred Annuity PV = Ordinary PV × (1+r)^−k

Perpetuities

  • PV (flat) = C ÷ r
  • PV (growing) = C₁ ÷ (r − g)

NPV

  • NPV = CF₀ + CF₁÷(1+r) + CF₂÷(1+r)² + … + CFₙ÷(1+r)^n
  • Accept if NPV > 0

IRR

  • Set NPV = 0, solve for r = IRR
  • Accept if IRR > required return (hurdle rate)

Profitability Index

  • PI = NPV ÷ |Initial Investment|
  • Accept if PI > 0

Equivalent Annual Annuity

  • EAA = NPV × r ÷ [1 − (1+r)^−n]
  • Use when comparing projects with different lives

Bond Pricing

  • P₀ = C × [1−(1+r)^−n]÷r + F÷(1+r)^n
  • C = Face Value × coupon rate (per period)
  • Premium: coupon rate > YTM; Discount: coupon rate < YTM

Gordon Growth Model (DDM)

  • P₀ = D₁ ÷ (r − g)
  • Required return: r = D₁÷P₀ + g
  • g = Retention Ratio × ROI = (1 − payout ratio) × ROI

HPR

  • HPR = (P₁ − P₀ + Dividends) ÷ P₀

CAPM

  • E[Ri] = Rf + βi × (E[RM] − Rf)
  • β > 1: more volatile than market; β < 1: less volatile

WACC

  • WACC = wE×RE + wP×RP + wD×RD×(1−TC)
  • V = MVE + MVP + MVD; wE = MVE÷V etc.
  • After-tax cost of debt = RD × (1−TC)
